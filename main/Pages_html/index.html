Je prépare aujourd'hui le diplôme d'ingénieur en génie logiciel à l'IIT de Sfax. En parallèle, je mène des projets DevOps (Docker, GitHub Actions, Azure, Prometheus / Grafana) et d'IA agentique (RAG, LangGraph), et j'utilise au quotidien des outils comme Claude Code et GitHub Copilot.
